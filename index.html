Settings & why some sources need a proxy

Wallhaven, Safebooru and the other non-Danbooru sources don’t send the header that lets a web page query them directly, so those requests go through a proxy chain: your local proxy first (run start.sh / start.bat), then your own Cloudflare Worker if you set one up (see worker/README.md), then a custom proxy if you enter one, then public fallbacks (corsfix, allorigins, cors.lol — flaky, tried last). Danbooru allows direct requests and never touches a proxy. The status line under each search tells you which path actually worked.
