Wallpaper Meta-Search

One search box, every wallpaper source. Results come from the sites that let a browser ask them directly, plus a CORS proxy for the ones that don't. No server, no account, no tracking.

Settings & why some sources need a proxy

Wallhaven, Safebooru and AlphaCoders don't send the header that lets a web page query them directly, so those requests go through a public CORS proxy. Danbooru allows direct requests and never touches the proxy. If a proxied source comes back empty, the proxy is probably down — pick another one, or use the site links below.

Prefer no proxy at all? Run the optional local proxy in proxy/ (node server.mjs) and set the proxy to http://localhost:8787/?url=.
